# Sprint 3 Plan

**Goal:** I will have a developed agent workflow: a team of subagents, with personas I can adapt
to future projects, designed to accelerate building, curriculum development, evals, and more by
working in parallel. Using these agents, I will build new teaching skills so the mentor can
teach After Effects basics beyond easing. I will also lay the groundwork for future sprints:
redesigning the user flows and interface, developing the mentor's diagnostic capabilities, and
building an installer.

**Why this:** I have validated the product idea and built a very simple MVP. Now that I know the
product can be built and that my target market wants it, I need to speed up how I build so I can
quickly grow the product's scope. To do that, I need to invest in new builder skills: agent
orchestration, skills, specs, and automations. The goal is to grow my overall capabilities as a
full-stack builder.

**Done looks like:**

- [ ] A team of agents in this repo that someone else could copy and deploy, with a setup README
- [ ] Proof the agents carry over: they're deployed in building my portfolio website
- [ ] At least one piece of work built by several agents in parallel, with notes on time and
      quality compared with building it alone
- [ ] 5 new After Effects teaching skills (the baseline), each run as a live lesson on my comp,
      with eval cases: key types (hold and linear), the speed graph, offset, setting the pivot
      (anchor point), and moving a group with a null
- [ ] Specs, developed with the agents, for:
  - [ ] the expanded After Effects curriculum
  - [ ] diagnostic tools
  - [ ] an installer
  - [ ] a UI overhaul

**Predicted difficulty:** 4
